## 3. Caveats

- **Network Interception in E2E**: Because tests run in headless Google Chrome without external network dependencies, YouTube watch pages are simulated using Puppeteer request interception (`page.setRequestInterception(true)`) responding with HTML containing `#movie_player` and `<video class="html5-main-video">`. This accurately isolates the extension's DOM behavior while ensuring fast, deterministic, offline execution.
- **CSS Animation Timing**: Drawer slide-in and overlay auto-hide employ CSS transitions (0.26s and 0.18s respectively). Tests use explicit `waitForFunction` and timeout buffers to ensure transitions settle before making click assertions.
- **CSS Animation `@keyframes ytPulse`**: In `src/styles.css`, `@keyframes ytPulse` was not explicitly defined (though the inline style sets `animation: ytPulse 1.5s infinite`). This does not prevent DOM execution or browser rendering of the pulsing dot, but could be added to `src/styles.css` in future polish.
